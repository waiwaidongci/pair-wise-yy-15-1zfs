# hxyfront-62014 赛鸽训放记录

训放负荷与休息放行台：在原有几条训放样例基础上，把“排训靠经验”补成按规则自动判定。

## 记录字段

- 足环号、放飞时间
- 距离（公里）、飞行分钟
- 是否归巢（未归巢不填距离/分钟）
- 恢复结论：恢复通过 / 恢复未通过 / 尚未评估
- 备注（训放地点、天气等）

## 负荷与放行规则（`src/lib/rules.ts`，纯函数判定层）

- 每 10 公里记 1 分，按最近七天累计；未归巢不计里程负荷。
- 命中以下任一条，该羽**只进休息队列**，不参加速度和名次排行：
  1. 百公里（≥100km）训放后两天内；
  2. 最近七天累计负荷到 6 分；
  3. 最近一次恢复评估未通过；
  4. 存在未归巢记录。
- 列表卡片与单羽档案均显示：七天累计负荷、最近长训（≥100km）、具体放行/休息原因。
- 速度与名次排行取每羽历史最佳分速（距离公里×1000÷分钟），休息队列自动排除。

## 修订与留痕（`src/lib/storage.ts`，保存层）

- 修改距离、放飞时间、分钟或恢复结论时，保存旧值快照（含修改时间与变更说明）。
- 保存后后续排训立即按新值重新判定；旧记录在单羽档案的“旧记录留痕”中仍可查。
- 数据持久化在浏览器 localStorage，首次打开自动生成按当前日期排布的样例数据。

## 分层

- `src/lib/rules.ts`：判定（负荷、休息窗口、排行），无 React、无存储；
- `src/lib/storage.ts`：保存（localStorage、新建、修订留痕、样例数据）；
- `src/components/*` + `src/App.tsx`：页面（表单、放行台、台账、单羽档案），只消费判定结论。
