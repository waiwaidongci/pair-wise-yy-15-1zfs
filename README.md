# hxyfront-62014 训放负荷与休息放行台

面向赛鸽棚的训放负荷与休息放行管理工具（React + Vite + TypeScript）。

## 规则

- 记录足环号、放飞距离、飞行分钟、归巢情况与恢复结论；
- 每 10 公里记 1 分，按最近 7 天累计负荷；
- 百公里训放后两天内、累计负荷到 6 分或恢复未通过时，只进休息队列，不参加速度和名次排行；
- 修改距离、时间或恢复结论后，后续排训立即重新判定，旧记录保留在单羽档案的变更历史中可查；
- 鸽棚总览与单羽档案展示累计负荷、最近长训与放行原因。

## 代码结构（判定、保存、页面分开承担）

- `src/domain/` — 判定层：数据模型与负荷/休息放行规则（纯函数）
- `src/store/` — 保存层：localStorage 持久化、记录增删改与修订历史
- `src/ui/` — 页面层：总览、休息与排行、训放记录、单羽档案
- `src/App.tsx` — 组装与导航
